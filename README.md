# Grid Governor

## Requirements

- Node.js 26 or later
- pnpm 11.20.0

## Install

```sh
pnpm install
```

## Develop

```sh
pnpm dev
```

The web app runs through Vite and proxies `/api` requests to the Hono API at `http://localhost:3000`.

## Validate

```sh
pnpm test
pnpm lint
pnpm typecheck
pnpm build
```
